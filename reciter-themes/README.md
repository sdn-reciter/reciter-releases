# Темы Reciter

Тема задаёт оформление приложения целиком: палитру, скругления, шрифты, фон,
форму панелей, плотность списка книг, картинки и значки. Это JSON-файл, рядом с
которым могут лежать картинки и шрифты. Здесь описан формат: какие ключи есть и
какие значения допустимы.

## Готовые темы

Готовые темы лежат в папке [`themes/`](../themes) этого репозитория:

- **«Шиноби»** — бумага и тушь, терракотовый акцент, днём и ночью;
- **«Газета»** — старая городская газета: пожелтевшая бумага, колонки, растр;
- **«Крупно и чётко»** — крупный шрифт, контрастные цвета, минимум картинок.

Скачивать их вручную не нужно: **Параметры → Галерея тем** показывает карточки всех
готовых тем, у нескачанных — кнопка загрузки, нажатие на карточку применяет
тему.

| В репозитории | В приложении |
|---|---|
| появилась тема | карточка с кнопкой загрузки |
| тему поправили | у скачанной — кнопка **«Обновить тему»** |
| тему убрали | скачанная продолжает работать |

Обновление проверяется, когда открыт экран тем; применённая тема после
обновления остаётся применённой. Готовая тема удаляется только с устройства —
карточка остаётся, тему можно скачать снова. Насовсем удаляются свои темы.

## Формат

Тема — папка с `theme.json` и ресурсами рядом; для обмена папка упаковывается в
ZIP. Голый `theme.json` тоже импортируется.

```
Моя тема.zip
├── theme.json      обязателен
├── bg.jpg          картинка фона
├── fontui.ttf      шрифт интерфейса
└── fontbook.ttf    шрифт текста книги
```

**Импорт:** Параметры → Галерея тем → значок импорта в шапке → файл `.zip` или `.json`.

Тема — только данные, без кода, поэтому чужой файл безопасен. Неизвестные ключи
пропускаются, значения вне диапазона заменяются ближайшими допустимыми,
испорченная секция — значениями по умолчанию. Тема от новой версии приложения
не ломает старую.

## Минимальная тема

Обязательно только `name`. Всё остальное необязательно.

```json
{
  "name": "Тёмный янтарь",
  "author": "sdn",
  "colors": { "background": "#1B1A17", "text": "#E8DCC8", "accent": "#D9A441" }
}
```

## Название на других языках

`names` — название темы на языках интерфейса: ключ — код языка (`en`), значение
— название. Приложение показывает название на своём языке интерфейса, а если
перевода нет — `name`. Секция необязательна.

```json
{ "name": "Тёмный янтарь", "names": { "en": "Dark Amber" } }
```

## Типы значений

| Тип | Запись | Примечание |
|---|---|---|
| цвет | `"#RRGGBB"` или `"#AARRGGBB"` | полностью прозрачный цвет считается «не задано» |
| dp | целое число | экранная единица Android |
| доля | число `0…1` | `0.9` = 90 % |
| градусы | целое `0…360` | 0 — слева направо, 90 — сверху вниз |
| набор | строка из списка | неизвестное значение → первый вариант |

## Параметры

### Дизайн-система

| Ключ | Тип | Значения | По умолчанию |
|---|---|---|---|
| `designSystem` | набор | `classic`, `brutalist` | `classic` |

`brutalist` — моноширинный шрифт, нулевые скругления, жирные рамки, острый
бегунок. Он перебивает выбор дизайн-системы в настройках приложения и форму
бегунка из `controls.sliderThumb`.

### Цвета приложения — `colors`

| Ключ | Тип | По умолчанию | Что красит |
|---|---|---|---|
| `background` | цвет | `#FFFFFFFF` | фон экранов |
| `text` | цвет | `#FF1A1A1A` | текст интерфейса |
| `accent` | цвет | `#FF6750A4` | кнопки, выделение, прогресс |
| `onAccent` | цвет | белый или чёрный по светлоте акцента | текст и значки на акценте: кнопки, выбранные вкладки и чипы, «Добавить книгу», кнопка пуска |

Остальная палитра (контейнеры, контуры, поверхности) выводится из этих трёх.
`onAccent` задавайте, когда акцент средней светлоты: белое по светло-розовому
или жёлтому не читается. Действует и в читалке.

### Цвета читалки — `reader`

Те же три ключа. Действуют на странице книги: фон, текст, акцент. Если секции
нет — берутся значения из `colors`.

### Скругления — `shapes`

Все в dp, диапазон `0…40` (`extraLarge` — до 64).

| Ключ | По умолчанию | Где видно |
|---|---|---|
| `extraSmall` | 6 | тонкие индикаторы |
| `small` | 10 | чипы, кнопки |
| `medium` | 16 | карточки |
| `large` | 22 | плашки, FAB |
| `extraLarge` | 28 | круглые кнопки, шторки |

Для брутализма обычно ставят все нули.

### Типографика — `typography`

| Ключ | Тип | Значения | По умолчанию |
|---|---|---|---|
| `fontFamily` | набор | `system`, `sans`, `serif`, `mono` | `system` |
| `scale` | доля | `0.7…1.6` | `1.0` |
| `fontFile` | имя файла | `.ttf` / `.otf` рядом с темой | — |
| `readerFontFile` | имя файла | `.ttf` / `.otf` рядом с темой | — |

`scale` умножает штатную шкалу — иерархия заголовков сохраняется.

`fontFile` — шрифт интерфейса, `readerFontFile` — текста книги: декоративный
шрифт хорош в заголовках и тяжело читается страницами. Шрифт, выбранный в
параметрах приложения, важнее шрифта темы; вернуть шрифт интерфейса темы —
«Шрифт интерфейса → Из темы» в «Оформлении и тексте».

Шрифт — один файл: жирное начертание приложение рисует из него само. Нужна
кириллица, иначе русские буквы выйдут запасным шрифтом. Шрифт под лицензией
SIL OFL кладите вместе с текстом лицензии, например `OFL-Alice.txt`: OFL
требует, чтобы она ехала вместе со шрифтом.

### Раскладка библиотеки — `layout`

| Ключ | Тип | Диапазон | По умолчанию |
|---|---|---|---|
| `gridMinSize` | dp | 70…220 | 110 |
| `gridSpacing` | dp | 0…32 | 10 |
| `contentPadding` | dp | 0…32 | 12 |
| `sectionGap` | dp | 0…32 | 6 |
| `coverRatio` | доля | 0.5…0.9 | 0.68 |
| `tabHeight` | dp | 24…48 | 30 |

- `gridMinSize` — минимальная ширина ячейки, а не число колонок: на планшете
  колонок больше, обложки не растягиваются.
- `gridSpacing` — зазор между обложками.
- `sectionGap` — промежуток между блоками списка («Продолжить чтение», карусели
  серий). К нему добавляются поля заголовка секции, поэтому на глаз он примерно
  вдвое больше заданного.
- `coverRatio` — ширина обложки к высоте: 0.68 — книжный формат, ближе к 0.9 —
  почти квадрат. Действует и в сетке, и в списке.
- `tabHeight` — высота ряда вкладок и ряда фильтров.
- `contentPadding` — поля списка книг со всех сторон, включая зазор под шапкой.

### Элементы управления — `controls`

| Ключ | Тип | Значения | По умолчанию |
|---|---|---|---|
| `sliderThumb` | набор | `bar`, `round`, `square` | `bar` |
| `sliderTrackHeight` | dp | 2…16 | 4 |
| `trackActive` | цвет | — | акцент |
| `trackInactive` | цвет | — | бледный акцент |
| `sliderLayout` | набор | `auto`, `compact`, `classic` | `auto` |

`bar` — штатная вертикальная черта Material; при `designSystem: "brutalist"`
бегунок всегда острый. `trackActive` — пройденная часть дорожки, `trackInactive`
— оставшаяся.

`sliderLayout` — вид ползунков в параметрах. `compact` — подпись, дорожка и
значение в одну строку; `classic` — подпись и значение над дорожкой; `auto` —
вид по умолчанию, в строку. Пока тема включена, вид ползунков задаёт она:
переключатель «Ползунки» в параметрах при теме не показывается. Тема с
крупным шрифтом ставит `classic`: в строку длинная подпись не помещается. В
строке бегунок `bar` короче и тоньше, а дорожка тонкая — ровно
`sliderTrackHeight`.

Форма, толщина и цвета действуют на все ползунки — перемотку в читалке и
настройки — и не действуют на полосы прогресса под обложками. `sliderLayout` на
перемотку в читалке не действует.

Картинку вместо бегунка задаёт одноимённый значок в секции `icons`
(`"icons": { "sliderThumb": "ic_thumb.png" }`, раздел «Значки»). Не путайте с
`controls.sliderThumb`: там форма, в `icons` — файл. Картинка важнее формы.

### Нижняя панель управления — `bars`

| Ключ | Тип | Значения | По умолчанию |
|---|---|---|---|
| `shape` | набор | `flat`, `rounded`, `wavy`, `notched` | `flat` |
| `curveHeight` | dp | 0…40 | 12 |
| `opacity` | доля | 0.2…1 | 1.0 |
| `inset` | dp | 0…32 | 12 |

`shape` — форма верхней кромки: ровная, скруглённые углы, волна, полукруглый
вырез под центральную кнопку. `curveHeight` — высота волны или глубина выреза.
`inset` — отступ от краёв экрана у видов `floating` и `pill`. Прижата панель
или оторвана от краёв, задаёт вид элемента `READER_BAR`.

### Шапка — `topBar`

| Ключ | Тип | Значения | По умолчанию |
|---|---|---|---|
| `shape` | набор | `flat`, `rounded`, `wavy` | `flat` |
| `curveHeight` | dp | 0…40 | 12 |
| `opacity` | доля | 0.2…1 | 1.0 |

У шапки фигурная кромка нижняя, и проходит она под строкой фильтров. Выреза
(`notched`) у шапки нет.

### Градиенты — `gradients`

| Ключ | Тип | По умолчанию | Что делает |
|---|---|---|---|
| `accent` | да/нет | `false` | градиент на акцентных элементах: кнопка воспроизведения, FAB, основные кнопки |
| `accentTo` | цвет | акцент со сдвигом яркости | второй цвет акцентного градиента |
| `angle` | градусы | 90 | направление обоих градиентов |
| `bars` | да/нет | `false` | градиент на панелях и шапке |

Без `accentTo` второй цвет — акцент, сдвинутый по светлоте примерно на 25 %.

### Поверхности — `surfaces`

| Ключ | Тип | Диапазон | По умолчанию |
|---|---|---|---|
| `opacity` | доля | 0.3…1 | 1.0 |
| `color` | цвет | — | не задан |
| `contentColor` | цвет | — | не задан |
| `rowOpacity` | доля | 0…0.9 | 0 |
| `borderWidth` | dp | 0…4 | 0 |
| `borderColor` | цвет | — | не задан |

- `opacity` — прозрачность карточек и плашек, чтобы сквозь них был виден фон-картинка.
  Обложки книг остаются непрозрачными.
- `color` — тон карточек и плиток (полки, серии, авторы, статистика); без него
  тон выводится из `colors.background`. Прозрачность задаёт `opacity`, альфа в
  самом цвете не учитывается — пишите `#RRGGBB`.
- `contentColor` — цвет текста и значков поверх своих картинок карточек и
  обложек (`images.card`, `images.cover`). Без картинки не действует.
- `rowOpacity` — полупрозрачная подложка под строками списка книг и под
  подписями обложек в плитке. Нужна, когда фон-картинка с рисунком и текст на
  ней теряется: 0.4–0.6 дают тексту опору, а фон остаётся виден. 0 — без
  подложки. Тон — `color`, а без него — цвет поверхностей темы.
- `borderWidth`, `borderColor` — рамка карточек и диалогов, у которых вид «в
  рамке» (`outlined`, `dialog_outlined`). Без них рамка штатная: 1 dp бледного
  тона. Теме для слабого зрения нужна заметная — 2 dp цветом текста.

### Уведомления — `notifications`

| Ключ | Тип | Диапазон | По умолчанию |
|---|---|---|---|
| `opacity` | доля | 0.4…1 | 1.0 |
| `inset` | dp | 0…32 | 16 |
| `contentInsetX` | доля | 0…0.35 | 0.11 |
| `contentInsetY` | dp | 0…40 | 10 |
| `imageFit` | `stretch` / `repeat` | — | `stretch` |
| `imageEdge` | доля | 0.01…0.4 | 0.08 |
| `contentColor` | цвет | — | не задан |

Действуют на все плашки сразу: статус операции, загрузка, удаление,
синхронизация, перевод, обновление, объявления.

- `inset` — отступ плашки от краёв экрана.
- `contentInsetX` (доля ширины) и `contentInsetY` (dp) — поля внутри плашки под
  рамку своей картинки (`images.notification`): валики свитка, рваную кромку.
  Без картинки не действуют. Подбираются по картинке: у свитка «Шиноби» валики
  занимают десятую долю ширины — `0.10`.
- `imageFit` — как картинка ложится по высоте. `stretch` растягивает её (свиток
  с валиками). `repeat` сохраняет пропорции: кромки сверху и снизу остаются, а
  середина повторяется или обрезается — для картинки с текстом или узором,
  которую растяжение сплющило бы.
- `imageEdge` — доля высоты картинки на каждую кромку, которая не повторяется.
  Если обе кромки не помещаются в плашку, картинка растягивается.
- `contentColor` — цвет текста и значков на картинке плашки. Задавайте, когда
  картинка по светлоте не совпадает с темой: светлый текст тёмной темы на
  светлом свитке пропадает.

### Видимость элементов — `visibility`

Все — `true` по умолчанию.

| Ключ | Что скрывает |
|---|---|
| `showBookTitles` | названия под обложками |
| `showBookAuthors` | авторов под обложками |
| `showProgressBadge` | значок прогресса на обложке |
| `showReaderProgress` | полосу прогресса в читалке |
| `showAnnouncements` | плашки объявлений |

Вкладки и фильтры скрываются через `elements` (`"TABS": { "hidden": true }`).
Блокирующие объявления (о неработающей версии) не скрываются.

### Виды элементов — `elements`

`elements` задаёт вид элемента интерфейса, скрыт ли он и что он делает по
нажатию. Пишите только элементы, отличные от штатных.

```json
"elements": {
  "TOP_BAR": { "variant": "large", "action": "open_settings" },
  "TABS":    { "hidden": true }
}
```

| Ключ | Тип | Значения |
|---|---|---|
| `variant` | набор | зависит от элемента, см. таблицу ниже |
| `hidden` | да/нет | только у элементов, помеченных «можно скрыть» |
| `action` | набор | `none`, `open_settings`, `back_to_library`, `back_to_book` |
| `order` | число | место блока внутри своей зоны, с нуля |
| `corner` | набор | `bottom_end`, `bottom_center`, `bottom_start` — только у `FAB` |

| Элемент | Что это | Виды (первый — штатный) | Можно скрыть |
|---|---|---|---|
| `TOP_BAR` | шапка | `bar`, `large`, `compact` | нет |
| `TABS` | вкладки библиотеки | `chips`, `underline`, `segmented` | да |
| `FILTERS` | фильтры по статусу | `chips`, `underline`, `segmented` (по умолчанию — как у `TABS`) | да |
| `READER_PROGRESS` | полоса прогресса в читалке | `progress_slider`, `progress_line` | нет |
| `READER_CONTROLS` | кнопки воспроизведения | — | нет |
| `BOOK_GRID` | сетка обложек | — | нет |
| `SECTION_HEADER` | заголовок секции библиотеки | `header_plain`, `header_accent`, `header_divider` | нет |
| `BOOK_CARD` | карточка книги | `elevated`, `outlined`, `flat` | нет |
| `EMPTY_STATE` | пустая библиотека | `with_icon`, `small_icon`, `no_icon` | нет |
| `FAB` | кнопка добавления | `extended`, `circle`, `mini` | нет |
| `READER_PAGE` | страница книги | — | нет |
| `READER_BAR` | панель управления | `docked`, `floating`, `pill` | нет |
| `BANNERS` | плашки уведомлений | `card`, `strip`, `plain` | нет |
| `DIALOG` | диалоги | `dialog_tonal`, `dialog_flat`, `dialog_outlined` | нет |
| `GROUP_CARD` | карточка полки, серии, автора | `outlined`, `elevated`, `flat` | нет |
| `STAT_CARD` | плитка статистики | `outlined`, `elevated`, `flat` | нет |
| `SETTINGS_CONTROLS` | ползунки и переключатели | — | нет |
| `SHEET` | шторка снизу (параметры, оглавление, поиск) | `with_handle`, `no_handle` | нет |
| `THEME_CARD` | карточка темы в галерее | `elevated`, `outlined`, `flat` | нет |

- Шапка, кнопка добавления и панель управления не скрываются: без них из
  приложения не выйти.
- `FILTERS` без своего вида повторяет вид `TABS`.
- `progress_line` убирает бегунок перемотки, остаётся дорожка толщиной
  `controls.sliderTrackHeight`; перемотка по дорожке работает.
- Неизвестный элемент, чужой вид и `hidden` у нескрываемого элемента
  пропускаются.

#### Компоновка

Блоки одной ЗОНЫ можно менять местами полем `order` (с нуля, по порядку сверху
вниз):

| Зона | Блоки |
|---|---|
| шапка библиотеки | `TABS`, `FILTERS` |
| панель управления читалки | `READER_PROGRESS`, `READER_CONTROLS` |

```json
"elements": {
  "FILTERS": { "order": 0 },
  "TABS":    { "order": 1 },
  "FAB":     { "corner": "bottom_center" }
}
```

Кнопка добавления переставляется углом (`corner`), а не порядком.

### Панели из частей — `blocks`

Шапку библиотеки, шапку читалки и панель управления можно собрать из частей:
логотип, название главы, счётчик страниц и каждая кнопка ставятся по
координатам внутри своей панели. Остальные элементы экрана по координатам не
ставятся — у них есть виды, порядок в зоне и `corner`.

Координаты задаются в dp внутри рамки телефона `canvasWidth` × `canvasHeight`
(корень файла, по умолчанию 360 × 720). По горизонтали они пересчитываются в
доли ширины рамки, поэтому часть у правого края остаётся у края на любом
телефоне; по вертикали остаются в dp.

Ключ в `blocks` — экран: `LIBRARY` для шапки библиотеки, `READER` для панелей
читалки. Значки частей и логотип берутся из `icons` и `images.logo`.

| Панель | Части |
|---|---|
| `TOP_BAR` (библиотека) | `LOGO`, `SEARCH_BUTTON`, `SORT_BUTTON`, `VIEW_BUTTON`, `ACCOUNT_BUTTON` |
| `READER_TOP_BAR` | `BACK_BUTTON`, `CHAPTER_TITLE`, `READER_SEARCH_BUTTON`, `BOOKMARK_BUTTON`, `READER_SETTINGS_BUTTON` |
| `READER_BAR` | `READER_PROGRESS`, `PROGRESS_TEXT`, `PREV_BUTTON`, `PLAY_BUTTON`, `NEXT_BUTTON`, `TIMER_BUTTON`, `TOC_BUTTON` |

Часть, которую не поставили, не рисуется. Пока не поставлена ни одна часть,
панель остаётся штатной.

```json
"blocks": {
  "LIBRARY": [
    { "element": "TOP_BAR",        "x": 0,   "y": 0,  "w": 360, "h": 56 },
    { "element": "LOGO",           "x": 16,  "y": 8,  "w": 160, "h": 40 },
    { "element": "ACCOUNT_BUTTON", "x": 264, "y": 8,  "w": 40,  "h": 40 },
    { "element": "SEARCH_BUTTON",  "x": 312, "y": 8,  "w": 40,  "h": 40 }
  ]
}
```

| Ключ | Значение |
|---|---|
| `element` | панель или её часть из таблицы выше |
| `x`, `y` | левый верхний угол, dp от угла экрана |
| `w`, `h` | размер, dp, не меньше 24; `0` — по содержимому |

Число вместо размера масштабирует часть: вдвое большая рамка — вдвое крупнее
значок или надпись, пропорции сохраняются. Каждую часть можно поставить один
раз; блок, записанный ниже в массиве, рисуется поверх записанных выше.

### Свои кнопки — `customElements`

Тема может добавить кнопку с функцией, которая в приложении уже есть.

```json
"customElements": [
  { "id": "e1", "slot": "reader_top_bar", "function": "bookmark" },
  { "id": "e2", "slot": "reader_bar",     "function": "sleep_timer" }
]
```

| Ключ | Значения |
|---|---|
| `id` | любая строка, уникальная в пределах темы |
| `slot` | `library_top_bar`, `reader_top_bar`, `reader_bar` |
| `function` | `search`, `bookmark`, `settings`, `sleep_timer`, `back`, `themes` |

`search` в библиотеке открывает строку поиска, в читалке — поиск по книге.
Кнопка с функцией, которой на экране нет (закладка в библиотеке), не рисуется.

### Фон приложения — `background`

| Ключ | Тип | Значения | По умолчанию |
|---|---|---|---|
| `type` | набор | `solid`, `gradient`, `image` | `solid` |
| `colors` | список цветов | ≥ 2 для градиента | — |
| `angle` | градусы | 0…360 | 90 |
| `image` | имя файла | картинка рядом с темой | — |
| `imageAlpha` | доля | 0…1 | 0.25 |

`solid` — фон из `colors.background`; `gradient` — не меньше двух цветов в
`colors`; `image` — картинка поверх заливки с прозрачностью `imageAlpha`.

## Картинки — `images`

Картинки под отдельные места экрана; слоты и размеры — в таблице выше.

```json
"images": {
  "appBackground":    "backdrop.jpg",
  "readerBackground": "parchment.jpg",
  "notification":     "scroll.png",
  "topBar":           "header.png",
  "bottomBar":        "player.png"
}
```

Картинка ложится «покрыть»: заполняет место целиком, лишнее уходит за край.
Поэтому:

- пропорции исходника — как у места: альбомная картинка на вертикальном экране
  теряет две трети ширины;
- середина спокойная и бледная: поверх идут текст и кнопки;
- по краям ничего важного — срежется или ляжет под первую строку.

Картинки панелей прижаты к своей кромке: `topBar` — к нижнему краю, `bottomBar` —
к верхнему. Декор рисуйте у этой кромки, у противоположной держите только
фактуру: там картинку срежет, особенно у низкой шапки. Форма панели (скругление,
волна) срезает и углы картинки.

Шторке (`sheet`) нужна картинка во весь экран: шторку поднимают до верха.

`bottomBarOverhang` — единственная картинка, которая выходит за панель.
Она ложится по ширине панели в своих пропорциях, серединой по высоте на
верхнюю кромку, и форма панели её не срезает. Верхняя половина висит над
панелью, поверх страницы книги; нижняя лежит на панели поверх её содержимого.
Над первой строкой панели около 30 dp (12 dp и `bars.curveHeight`), а 1440 px
картинки на телефоне — около 340 dp. Поэтому при полосе 6:1 (1440×240) нижняя
половина занимает около 28 dp и в строку не заходит. Ниже середины рисуйте
только то, что лежит на самой кромке: отверстия и концы колец.

- `cover` — обложка книг без своей обложки. Первая буква названия остаётся
  поверх белым; если белое не читается, задайте `surfaces.contentColor`.
  Пропорции — как в `layout.coverRatio`.
- `card` — подложка карточек полок, серий, авторов и плиток статистики вместо
  заливки. Цвет подписей на ней — `surfaces.contentColor`.
- `emptyState` — иллюстрация вместо значка пустой библиотеки, около 180 dp (96 dp
  при виде `small_icon`, не видна при `no_icon`).
- `preview` — миниатюра темы в галерее, около 150×150 dp; в самом приложении не
  рисуется. Не задана — миниатюра собирается из фона, панелей и страницы.

Подложки панелей, шторки и плашек лежат под текстом цвета `colors.text`: у
тёмной темы он светлый, поэтому и подложки нужны тёмные. Светлая подложка
подходит `readerBackground` — там текст цвета `reader.text`.

Картинки в памяти распакованы: держите ширину 1000–1500 px.

## Значки — `icons`

Свои значки вместо штатных; ключи — в таблице файлов выше.

```json
"icons": {
  "search":   "ic_search.png",
  "play":     "ic_play.png",
  "settings": "ic_settings.png"
}
```

- Значок рисуется как есть, без перекраски: он должен читаться на всех панелях,
  где стоит кнопка. Фон — прозрачный.
- Квадрат 256×256, поле вокруг рисунка — около шестой части стороны.
- Кнопки с двумя состояниями: `play` / `pause`, `bookmark` / `bookmarkOn`. Без
  `bookmarkOn` стоящая закладка рисуется тем же значком цветом акцента.
- Кнопки «назад» и «вперёд» шагают на абзац, страницу или главу — как выбрано в
  параметрах; значок берётся под шаг (`prev`, `prevPage`, `prevChapter`), а без
  своего значка шага — `prev` / `next` темы.
- Кнопка «День / Ночь» показывает, во что переключит: днём `nightMode`
  (обычно луна), ночью `dayMode` (солнце). Она, кнопка усиления `volumeBoost`
  и кнопки `sliderMinus` / `sliderPlus` видны, только когда включены в
  параметрах.
- Кнопка вида: `viewMode` (сетка), `viewList`, `viewCompact`. Незаданный значок
  вида — штатный.
- Значки вкладок (16 dp) появляются только у вкладок, которым они заданы.
- Значки плашек и бейджи — 9–18 dp: рисуйте силуэтом, детали пропадут.
- Бегунок `sliderThumb` рисуется в 28 dp поверх дорожки, центр картинки — на
  текущем значении. Поле вокруг рисунка не нужно: оно сделает бегунок мельче.
- Значок блокирующего объявления темой не меняется.

## Значки авторов — `authorIcons`

Свой значок на первую букву имени автора: ключ — буква, значение — файл.

```json
"authorIcons": {
  "А": "ic_author_a.png",
  "Б": "ic_author_b.png",
  "S": "ic_author_s_lat.png",
  "default": "ic_author_other.png"
}
```

Имя файла латинское, буква — только в ключе. Поиск для автора «Стивен Кинг»:
`authorIcons["С"]` → `authorIcons["default"]` → `icons.author` → буква в кружке.

- Ключ — одна буква; регистр и лишние буквы не важны, берётся первая.
- Имя, начинающееся с цифры или кавычки, идёт в `default`.
- «Е» и «Ё», латинская `S` и русская «С» — разные ключи.
- Значок обрезается по кругу и заполняет его целиком: рисуйте без поля.
- Все буквы задавать не нужно; 33 файла 256×256 — около полумегабайта.

## День и ночь — `dark`

Секция `dark` — ночная половина темы. Она действует, когда оформление тёмное:
в телефоне или в выборе «Светлое / Тёмное» в галерее тем.

```json
{
  "name": "Шиноби",
  "colors": { "background": "#EDE6D2", "text": "#2A2018", "accent": "#C2410C" },
  "images": { "appBackground": "backdrop.jpg", "sheet": "sheet.jpg" },
  "icons":  { "search": "ic_search.png" },

  "dark": {
    "colors": { "background": "#1C1712", "text": "#EDE0C8", "accent": "#E2661A" },
    "background": { "type": "gradient", "colors": ["#1C1712", "#0F0C09"] },
    "images": { "appBackground": "", "sheet": "" },
    "icons":  { "search": "ic_search_night.png" }
  }
}
```

- Внутри `dark` — те же секции и ключи, что в теме.
- Ночь накладывается на день: пишите только отличия.
- Пустое имя файла снимает картинку ночью: `"appBackground": ""`. Фон задают два
  ключа — `images.appBackground` и `background.image`; снимайте оба.
- Без секции `reader` ни в теме, ни в `dark` палитра читалки ночью следует за
  ночными `colors`.
- `dark` внутри `dark` не читается.
- Ночным файлам нужны свои имена: `ic_search_night.png` рядом с `ic_search.png`.

Тема без `dark` одна на любое время суток.

## Готовая тема за основу

Проще всего начать с **«Шиноби»**: в ней задействована большая часть формата.
Архив — в [`themes/`](../themes).

```
shinobi.zip
├── theme.json      палитра, формы, шрифты, раскладка, ссылки на файлы
├── backdrop.jpg    фон приложения
├── parchment.jpg   страница книги
├── topbar.jpg      шапка
├── bottombar.jpg   панель управления
├── sheet.jpg       подложка шторки параметров
├── scroll.png      подложка плашки уведомления
├── logo.png        знак в шапке библиотеки
├── preview.jpg     обложка темы для карточки в списке
├── ic_*.png        значки кнопок
└── *_night.*       те же картинки и значки для ночной половины
```

1. Распакуйте архив.
2. В `theme.json` поменяйте цвета и обязательно `name` (и `names`) — иначе в
   списке не отличить от оригинала.
3. Замените картинки своими с теми же именами или пропишите новые имена в
   `images` и `icons`.
4. Упакуйте содержимое папки в ZIP и импортируйте.

Лишнее удаляйте: необязательно всё, кроме `name`. Без `images` остаётся палитра,
без `icons` — штатные значки.

## Обмен темами

Параметры → Галерея тем → долгое нажатие на карточку → «Поделиться»: приложение
соберёт ZIP с `theme.json` и всеми файлами.

## Ограничения

- Шрифты — только `.ttf` и `.otf`; битый файл при импорте отбрасывается.
- Архив ограничен по объёму; пути внутри архива пропускаются, берутся имена
  файлов.
- Своя тема заменяет штатную целиком; выбор штатной палитры в параметрах снимает
  свою тему.
- Палитра — фон, текст и акцент (и такая же тройка для читалки, и ночная пара).
  Своих цветов у полос прогресса и бейджей нет — они от `colors.accent`.
- Своя подложка — у приложения, читалки, панелей, плашек, пустой библиотеки и
  карточек. Экраны параметров и галереи тем берут подложку `sheet`.
- Значки меняются только из списка `icons` и `authorIcons`; пункты меню,
  галочки выделения и значки параметров — штатные.
- По координатам ставятся только части панелей (`blocks`).
- Нижней панели вкладок в приложении нет.
- Тема меняет вид, но не поведение: `customElements` выбирают из того, что
  приложение уже умеет.
