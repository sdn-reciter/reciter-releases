# Confucius4-TTS

Клонирует голос по образцу в 5–12 секунд, расшифровка образца не нужна.
14 языков, среди них русский. Звук 22 кГц.

## Запуск

```bash
docker build -t reciter-tts-base:cu128 ../base   # один раз, если базы ещё нет
cp .env.example .env                             # ключ и настройки
docker compose up -d --build
```

Первая сборка качает веса модели — несколько гигабайт, до получаса. Они
запекаются в образ, на старте сеть не нужна.

## Голоса

Образцы — wav-файлы (5–12 с чистой речи, один человек, без музыки) в
`./voices/`, либо загрузка через `POST /voices/upload`. Без образца сервер
не говорит. Образец длиннее `CONFUCIUS_REF_MAX_SEC` обрезается.

## Ударения

Метки ударения модель не понимает, сервер их убирает перед синтезом.
Словарь ударений приложения на этом движке не действует.
